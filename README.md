# Embedded Systems – Grunder

Mina personliga anteckningar om inbyggda system och elektronik.

## Mikroprocessor
- Datorns hjärna.
- Bearbetar data och utför instruktioner.
- Styr olika operationer i ett system.

## Sensor
- Upptäcker och mäter förändringar i omgivningen.
- Kan mäta temperatur, ljus, rörelse och avstånd.
- Skickar information till ett elektroniskt system.

## Arduino
- En plattform för elektronik och programmering.
- Innehåller en mikrokontroller.
- Kan kopplas till sensorer, lampor och motorer.
